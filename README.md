# Assessing the Detectability Threshold of Acoustic Signatures

This repository contains the supplementary source code, analytical datasets, and multimedia audio files for the research paper: **"Assessing the Detectability Threshold of Acoustic Signatures Using Phase-Coupling and Information Theory in Real Ocean Backgrounds"** submitted to *Acta Acustica*.

## 🎧 Supplementary Audio Files (The Masking Effect)
To physically demonstrate the extreme masking threshold (-20 dB SNR) discussed in the paper, we have provided isolated and mixed audio samples in the `/Audio` directory. Reviewers and readers are highly encouraged to listen to these samples to experience the acoustic obfuscation firsthand:
*   `Audio_1_Pure_Vessel_Signature.mp3`: The isolated deterministic mechanical target (ShipsEar dataset).
*   `Audio_2_Pure_Deepwater_Noise.mp3`: The baseline non-Gaussian hydrodynamic interference (NOAA ADEON dataset).
*   `Audio_3_Mixed_Signal_10_Percent.mp3`: The vessel signature injected into the deep-water noise at a 10% amplitude ratio. The mechanical signature is entirely absorbed by the ocean's acoustic dynamics.

## 📁 Repository Structure
*   `/Audio`: Contains the `.mp3` supplementary files referenced in the manuscript.
*   `/Code`: Python scripts utilized for the multi-domain signal processing (Energy, Morphology, Phase, and Time).
    *   `Result_8_Classical_Sonar_FFT.py`: Baseline energy evaluation and spectrogram generation.
    *   `Result_14_Bispectrum_Analysis.py`: Higher-Order Statistics (HOS) for phase-coupling detection.
    *   `Result_17_Information_Theory.py`: Permutation Entropy (PE) and temporal chaos analysis.
*   `/Results`: High-resolution figures and output matrices generated by the algorithms (AST Heatmaps, Phase Contours, PDF distributions).

## 💻 Requirements
The analytical framework was developed in Python. To reproduce the results, the following dependencies are required:
*   `numpy`
*   `scipy`
*   `matplotlib`
*   `librosa` (for acoustic signal loading and filtering)
*   `antropy` (for Permutation Entropy and fractal complexity)

## 🚀 Usage
Clone the repository and run the scripts within the `/Code` directory. Ensure that your local environment is pointed to the correct dataset paths if you are using the raw ShipsEar or ADEON databases.

```bash
git clone https://github.com/AmirhosseinDoost/acoustic-stealth-threshold.git
cd acoustic-stealth-threshold/Code
python Result_17_Information_Theory.py
```
